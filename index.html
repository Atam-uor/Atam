АТАМ

Абсолютный рекорд среди конечных чисел, рожденный из мысленного эксперимента по преодолению квантового барьера.

Атам = Nmax + 1

Симулятор квантового туннелирования

Попробуйте протолкнуть палец сквозь стену. Для успеха нужно Атам попыток.

Попыток: 0
Осталось: Атам − 0
Стена нерушима. Электронные облака отталкивают палец.

Что такое Атам?

Атам — концептуальное сверхбольшое число, равное наибольшему строго определенному конечному числу в математике плюс один.

Оно показывает, что у конечных чисел нет предела, но даже Атам бесконечно мал по сравнению с бесконечностью (ℵ₀).
